# Full-Stack Application with Docker

A complete full-stack application featuring React frontend, Spring Boot backend, MariaDB database, with Prometheus and Grafana monitoring.

## 🚀 Quick Start

### Prerequisites
- Docker Desktop installed and running
- Git

### Run the Application

```bash
git clone https://github.com/omar-ababou/full-stack-app.git
cd full-stack-app
git checkout omar-docker-setup
docker-compose up --build
```

## 🌐 Access Services

| Service | URL | Credentials |
|---------|-----|-------------|
| **Frontend** | http://localhost:3000 | - |
| **Backend API** | http://localhost:8080/api | - |
| **Swagger UI** | http://localhost:8080/swagger-ui.html | - |
| **Prometheus** | http://localhost:9090 | - |
| **Grafana** | http://localhost:3001 | admin/admin |
